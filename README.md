# itdepends

## How to Build

```
cargo build --release
```

## Usage

```
Formatting dependencies generated by Java build tools

Usage: itdepends [OPTIONS] --builder <BUILDER> <INPUT_FILE>

Arguments:
  <INPUT_FILE>  

Options:
      --offline            Stop fetching metadata from network
  -b, --builder <BUILDER>  Builder that generated the input file [possible values: maven, gradle]
  -h, --help               Print help
  -V, --version            Print version
```

### Using with Maven

```shell
cd /path/to/your/project
mvn org.apache.maven.plugins:maven-dependency-plugin:3.10.0:tree '-DoutputType=json' '-DoutputFile=deps-tree.json'
itdepends -b maven deps-tree.json
```

### Using with Gradle

```shell
cd /path/to/your/project
gradle dependencies > deps-tree.txt
itdepends -b gradle deps-tree.txt
```
